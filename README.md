# IB CS Revision Help, Privacy & Terms

Public support, privacy and terms information for the IB CS Revision app.

## Routes

- `/` — help centre landing page
- `/privacy` — privacy policy
- `/terms` — terms of use
- `/support` — support and troubleshooting

## Development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` are exported as a static site and deployed through GitHub
Pages. The production site is available at
`https://grigor-dochev.github.io/ib-cs-revision-help/`.
